Freeze & flatten to a workspace (archival, hand-edit)

Flatten one build variant into a single self-contained output/frozen-<variant>-<timestamp>/cv.typ whose body is literal Typst markup — one explicit call per entry. Edit any entry directly (fix a title, bold a word, nudge layout) and render with the included render.sh. The layout helpers and typography are inlined; fonts/ is the only other file. All flags are baked in for the chosen variant (no --input); to change a flag, edit the markup or re-freeze a different variant. Unlike the flattened .typ above, a frozen workspace is kept until pruned (30d).
